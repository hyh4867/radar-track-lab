## 2. 1부 방법: G1 (`src/radar_track_lab/cone.py` ConeHoldV2Mixin, `gate_all=True`)
- 5단계 H1(원뿔 유지 + 원뿔을 나오는 항적의 고도 확인)은 그대로 켠다.
- **G1 대상**: H1의 고도 확인 대상이 아닌 확정 항적 가운데 Mode C 기록이 있는 항적.
- **G1 규칙**: 대상 항적은 Mode C가 있는 표적 보고 중 예측 고도 ±Δh 안인 것만 받는다. 기존 2차원 게이트는 그대로 거친다.
  - 예측 고도와 Δh는 5단계 H1과 같은 식이다. 예측 고도 = 마지막 Mode C + v_z × 경과 시간이다. Δh = 200 ft + 50 ft/s × 경과 시간이다. v_z는 최근 30 s Mode C의 최소제곱 기울기로, ±100 ft/s로 자른다.
- **고도가 없는 보고**(허위 탐지, 또는 R의 Mode C 누락)는 G1 대상 항적에도 2차원 게이트만으로 붙을 수 있다. 지시문의 "고도가 없는 보고와 고도가 없는 항적은 지금처럼 2차원 게이트만 쓴다"를 그대로 따랐다.
  - H1의 고도 확인 대상(유지 중이거나 막 나온 항적)은 5단계처럼 고도 없는 보고를 받지 않는다.
- **G1에서 빼는 항적**: 미확정(tentative) 항적과 Mode C 기록이 없는 항적. 이들은 2차원 게이트만 쓴다.
- **Mode C 사용**: Mode C를 연관에 쓰는 실제 SSR 추적과 같은 정보를 쓴다. 오차 없는 조건(기본)과 오차를 넣은 조건(R)을 모두 본다.

## 3. 강건성 R: Mode C 오차 가정 (`cone.apply_modec_errors`)
- 표적 보고마다 독립으로 2%는 고도 누락(NaN), 1%는 잘못된 고도다. 잘못된 고도는 0–45,000 ft 균등 무작위 값을 100 ft로 양자화한 것이다. **문헌 값이 아니라 가정값이다.**
- 난수는 seed별 별도 흐름((seed, 6060))이라 탐지와 클러터는 오차 없는 조건과 같다.
- 오차는 추적기가 보는 보고의 고도에만 넣는다. 센서 모형의 경사거리 보정은 3단계 그대로 참 Mode C를 쓴다(해석).
- R 조건에서는 H1과 H1+G1을 같은 오차로 돌린다. M4는 Mode C를 쓰지 않으므로 R을 돌리지 않는다.

## 4. 교차 사건 지표 (`src/radar_track_lab/crossing.py`)
- **교차 사건**: 기준 궤적(scan truth의 조사 시각 위치와 기압 고도)에서 두 항공기가 수평 2 km 안이고 고도 차가 1,000 ft 이상인 연속 scan 구간이다.
- **교차 사건 바뀜**: 두 항공기 중 하나의 ID switch로, 그 switch의 [k_last, k_new]가 사건 구간 ±3 scan과 겹치는 것이다. switch 하나는 한 번만 센다. warm-up 뒤 switch만 센다(3단계 분류와 같음).
- 사이트 한계 문구("서로 다른 고도에서 경로가 교차하는 항공기를 구분하지 못합니다")를 직접 재는 지표다.

## 8. 2부: 데이터로 정하는 바닥값 (1부 보고서를 push한 뒤에만)
- **방법** (`AdaptiveClutterMapDensity(floor_frac=f)`): 칸마다 바닥값 = max(f × 그 칸 상한 창(9 km × 22.5°)의 추정 밀도, FLOOR/10). FLOOR = 2.546e-5 /(m·rad)/scan이고 FLOOR/10은 절대 하한이다. 나머지(n_min 20, τ 30, 넓히기, 제외 규칙)는 5단계 동결값 그대로다.
- **후보**: f ∈ {0.25, 0.5, 1.0}. f = 1.0이면 밀도가 상한 창 추정값 아래로 내려가지 않는다(거친 추정 쪽으로 줄이기).
- **선택**: 조정 구간만 쓴다. EHAM_1106_tune, M0, seed 20271106–20271110, lam5_map과 lam1000_uniform이다.
  - 점수 = max(두 조건의 JIPDA-amap(f) GOSPA / JIPDA GOSPA). 가장 작은 후보를 고른다. 동점(넷째 자리)이면 두 조건 놓친 표적 합이 작은 쪽을 고른다.
  - JIPDA 기준값: lam1000_uniform은 `results/stage5/tune/EHAM_1106_tune__jipda__lam1000_uniform.json`, lam5_map은 새로 돌린다.
  - 참고로 5단계 JIPDA-amap(고정 바닥값)도 lam5_map 조정 구간에서 돌려 함께 적는다. 선택에는 쓰지 않는다.
  - 고른 f는 `configs/stage6.yaml`에 쓰고 커밋한 뒤 평가한다.
- **평가**: 5단계와 같다. EHAM_1106_eval, M0, seed 20261106–20261125, 다섯 조건(lam1000_map, lam1000_uniform, lam200_map, lam5_map, lam5_uniform)이다. 비교 대상은 5단계 JIPDA-amap(`results/stage5/eval/`)과 JIPDA다.
- **판정**:
  - (a) 나쁘지 않음: 다섯 조건 모두 GOSPA seed 평균 비율(새 방법 / 5단계 JIPDA-amap) ≤ 1.01
  - (b) λ5 손해 감소: lam5_map과 lam5_uniform 모두, 놓친 표적과 확정 지연 각각의 짝 차이(새 방법 − 5단계 JIPDA-amap) 95% 상한 < 0
  - **개선**: (a)와 (b). **부분 개선**: 하나만. **개선 없음**: 둘 다 아님.

## 10. 해석 (지시가 모호했던 곳)
