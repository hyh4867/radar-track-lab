## 결론

- 기준선의 연관과 항적 관리는 그대로 두고 출력에만 직선 외삽을 붙이면, 세 방법 공통 표본의 scan-end RMSE가 527.3 m에서 315.9 m로 줄어듭니다. EKF는 174.1 m입니다.
- 기준선과 EKF의 차이 353.3 m 가운데 211.5 m(59.9%)가 이 한 단계에서 사라집니다. 사전에 적은 규칙으로 README 문장의 "scan 사이 예측" 부분은 **지지**입니다. 스히폴 평가 구간 하나에 대한 결과입니다.
- 남은 141.8 m는 필터의 평활과 연관(gating, 전역 배정)이 함께 만든 것이고 이번 실험은 그 둘을 나누지 않습니다.
- 3단계 감사의 설명 하나를 고쳐야 합니다. 기준선의 끊김과 놓친 표적을 "항적 번호 유지"의 근거로 들었는데, 연관이 같은 변형에서 끊김이 414.2회에서 123.3회로, 놓친 표적이 4.02에서 1.49/scan으로 줄었습니다. 이 감소분은 연관 실패가 아니라 출력 위치가 2 km 넘게 벗어나 생긴 것입니다. 연관의 차이를 직접 보여 주는 지표는 ID switch입니다(459.2 대 463.6 대 24.9회).

## 변형의 정의

- 연관, 항적 생성·확정·삭제, 커버리지 밖 삭제 판정은 기준선과 같습니다. 예측 위치를 연관에 쓰지 않습니다.
- 속도는 기준선이 이미 계산해 두던 값입니다: 항적에 연결된 최근 두 탐지점의 위치 차 ÷ 시각 차. 평활이나 보호 장치는 없습니다.
- scan 끝 시각의 출력 위치만 "마지막 탐지점 + 속도 × 지난 시간"으로 바뀝니다. 조정한 매개변수는 없습니다.
- 변형은 이것 하나만 만들었습니다.

### 주 지표: 세 방법 공통 표본의 scan-end RMSE

워밍업 뒤 표적-scan은 run당 18,256개입니다. 세 방법 모두 짝이 있는 것이 16,768개, 세 방법 모두 없는 것이 288개입니다.

| 방법 | 짝이 있는 표본/run | 공통 표본 RMSE (m) | 각자의 표본 RMSE (m) |
|---|---:|---:|---:|
| 기준선 | 16,799 | 527.3 ± 1.3 | 528.1 ± 1.4 |
| 기준선 + 출력 예측 | 17,715 | 315.9 ± 1.2 | 358.6 ± 1.0 |
| EKF | 17,958 | 174.1 ± 1.3 | 174.7 ± 1.2 |

| 단계 | 공통 표본 RMSE의 짝 차이 (m) |
|---|---:|
| D_pred: 기준선 → 출력 예측 추가 | −211.46 [−213.30, −209.61] |
| D_rest: 출력 예측 추가 → EKF | −141.80 [−143.35, −140.25] |
| D_total: 기준선 → EKF | −353.26 [−354.91, −351.61] |

- |D_pred| / |D_total| = 0.599. 판정 규칙(D_pred의 구간이 전부 0 아래, 비가 0.5 이상)에 따라 "지지"입니다.
- 이 비는 "기준선 → 출력 예측 추가 → EKF" 순서로 바꿨을 때의 값입니다. 순서를 바꾸면 달라질 수 있어서 원인별 기여도로 쓰지 않습니다.
- D_total이 감사의 −353.93 m와 조금 다른 것은 공통 표본이 두 방법 교집합(16,788개)에서 세 방법 교집합(16,768개)으로 바뀌었기 때문입니다.
- 변형은 각자의 표본에서 358.6 m로 공통 표본보다 높습니다. 기준선이 짝을 못 만들던 표본 약 900개를 새로 얻었고 그 표본의 오차가 크기 때문입니다.
